## The day, on Lexli

*The mirror of the section above — same moments, transformed. Structured evening → morning → at the court → after.*

**The evening before.** The board has already built itself from the published cause lists — every court, verified, with the last orders attached. You read it; you don't assemble it. `[VERIFY: live cause-list verification — carries the Daily Board page's flag]`

**In the morning.** The case record is in your pocket: parties, acts, hearing history, the note you made after the last date. Multi-device — the desk, the corridor, the courtroom door.

**The paperwork.** Ask for the application and it arrives with the case details already in it — because the platform read the file when the case did. You write the argument; the re-typing is over. `[VERIFY: pre-fill shipped — carries the Drafting page's flag]`

**After the hearing.** The note goes in the case. The order lands in the file when it's published. And the client's question now has a one-minute answer, because the record is the answer.
